# Book Parser

A scraper for [books.toscrape.com](https://books.toscrape.com/).

## Versions

- **v0** — a draft built to verify that scraping is possible. Stays in the repo as-is.

## Installation

Run the following commands **from the project root directory** (the folder containing `v0.py` and `requirements.txt`).

```bash
# 1. Create a virtual environment
python -m venv venv

# 2. Activate it
# Linux / macOS:
source venv/bin/activate
# Windows (cmd/PowerShell):
venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt
```

## Usage

```bash
python v0.py
```
